
**Newly generated missions after the mod is enabled** will have their enemy count capped as if a faction had X power if their power is higher. X can be configured on MCM window.

**Need to restart the game after MCM config setup for this mod to take effect**

This mod will not impact outcome of a mission where you were not involved.
